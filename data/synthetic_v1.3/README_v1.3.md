# 게임형 적금 합성 데이터 v1.3

공개 지표(누적 계좌·재가입률·연령 분포)와 논문 효과 크기로 보정하고, **v1.1에서는 공개 실데이터(KKBox·은행 이탈·Hillstrom·cookie_cats)의 패턴까지 맞춘** 가상 개인 단위 데이터입니다. 실제 고객 데이터가 아니므로 포트폴리오에는 "합성 데이터(공개 지표·실데이터 패턴 기반 보정)"로 표기하세요.

- 기준일 2026-10-31 · 난수 seed 고정
- 재현 순서: `python sim.py` → `python validate.py` → `python export.py` (CSV 9개·DB·엑셀을 같은 결과로 동시에 다시 씀) → `python validate_v2.py` (배포된 CSV를 직접 읽어 금융권식 28개 검증, 결과 `csv/_validation_v2.csv`)
- `MANIFEST.csv`: 파일별 행 수와 SHA-256 — 받은 파일이 이 버전인지 확인용
- 필요 패키지: Python 3.10+ · pandas · numpy · scipy · scikit-learn · openpyxl (`pip install pandas numpy scipy scikit-learn openpyxl`) — `validate_v2.py`는 scipy가 있어야 실행됨
- 엑셀(`게임형적금_합성데이터_v1.3.xlsx`)의 users·accounts·payments·tree_cycles·ab_experiment 탭은 **무작위 5,000행 미리보기**(탭 이름 `_미리보기`). 분석은 `csv/` 또는 `gamified_synthetic.db`의 전체 데이터로

### 용어: 납입 중단 vs 계좌 종료
| 컬럼 | 뜻 |
|---|---|
| `중단_회차` | 납입이 멈춘 회차. 기준일 이전에 일어난 중단만 기록 |
| `상태` | 계좌가 끝났는지 — 진행중 / 중도해지 / 만기(우대·기본·8%·10%) |

납입을 멈춘 계좌 중 약 30%만 해지하고(가정), 나머지는 해지하지 않고 남습니다. 그래서 `중단_회차`가 있어도 `상태`가 **진행중**(만기 전, 412건)이나 **만기(기본)**(우대 조건 미달로 만기)일 수 있으며 데이터 오류가 아닙니다. 중도해지 계좌만 금리 0.5%이고 해지 이후 납입 행이 없습니다.

### A/B 효과의 시드 안정성 (실험 부분만 20회 재생성)
| 효과 | 20회 평균 | 표준편차 | BH 유의 비율 |
|---|---|---|---|
| B안 21일 달성 | +3.3%p | 0.8%p | 100% |
| B안 7일차 유지 | +3.2%p | 0.8%p | 95% |
| B안 7일 내 재가입 | +4.1%p | 0.8%p | 100% |
| B안 31일 완주 | -0.0%p | 0.7%p | 0% |
| C안 7일 내 재가입 | +2.0%p | 0.6%p | 85% |
| C안 첫날 저금 | +1.0%p | 0.3%p | 70% |

→ B안 효과 3개만 안정적. C안 효과와 B안 완주율 변화는 시드에 따라 유의 여부가 바뀌므로 결론으로 쓰지 않습니다. (v1.1에서 본 B안 완주 −1.4%p는 우연)

## 남은 한계
- 논문 수치는 다른 맥락에서 가져왔습니다: 이승민(2022)은 20대 대학생 137명, Silverman & Barasch(2023)의 복구 효과는 단어·숫자 게임 실험, Baptista & Oliveira(2017)는 브라질 은행 고객, Kearney et al.(2010)은 상금연계저축이 총저축을 늘린다는 근거가 아니라 참여 동기 근거입니다.
- 토스 끊김 패널티 ×0.47은 log-odds 척도 기준이며, 확률 격차 기준이면 ×0.32입니다 (가정).
- 26주·한달·토스 sBG 값은 Fader & Hardie 논문 값이 아니라 KKBox 곡선 모양에 맞춘 보정값입니다 (구조만 차용).
- 26주·한달 완주율(55%·45%)은 공개 자료가 없는 가정입니다.
- 실데이터 패턴은 다른 분야(음원 구독·은행·이메일)에서 가져온 '모양'이라, 게임형 적금의 실제 수치와는 다를 수 있습니다.
- 재가입 회차별 상승폭(38%→71%)은 KKBox(84%→94%)보다 가파릅니다.
- 몰입→지속사용의도 상관은 0.60으로 논문(.716)보다 약합니다.
