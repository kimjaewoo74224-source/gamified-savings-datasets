# 합성데이터 생성 코드 — 통계 기반 vs 규칙 · 시뮬레이션 기반

| 파일 | 방식 | 필요한 재료 | 근거 논문 |
|---|---|---|---|
| `stat_synth.py` | 통계 기반: 가우시안 코퓰라 · 순차 CART · IPF | 원본 행 (IPF는 집계표만) | Patki et al. 2016 (SDV) · Nowok et al. 2016 (synthpop) · Beckman et al. 1996 |
| `rule_sim_synth.py` | 규칙 · 시뮬레이션 (26주적금 핵심 로직) | 공개 수치 + 논문 효과 크기 + 업무 규칙 | Fader & Hardie 2007 (sBG) · Silverman & Barasch 2023 (연속 기록) |
| `sim_v13_full.py` | 규칙 · 시뮬레이션 (v1.3 전체: 상품 5개 · 설문 · A/B · KPI) | 위와 같음 | + 이승민 2022 · Deng et al. 2013 |
| `evaluate.py` | 공통 평가: 분포 유사도 · 상관 차이 · 판별 AUC · TSTR · 효과 보존 | — | Snoke et al. 2018 · Xu et al. 2019 |

## 실행

```bash
pip install numpy pandas scipy scikit-learn
python stat_synth.py churn.csv out_stat        # Kaggle Bank Customer Churn (원본이 있는 공개 데이터)
python rule_sim_synth.py out_rule 10000       # 원본 없이 생성 (1초 안팎)

```

## 결과 예시

통계 기반 (은행 이탈 데이터 7,000행으로 학습 · 3,000행으로 시험, 판별 AUC는 0.5가 최선)

| 방식 | 분포 유사도 | 상관 차이 | 판별 AUC | TSTR AUC (진짜 학습 0.853) | 활동 회원 효과 (진짜 −13.6%p) |
|---|---|---|---|---|---|
| 독립 추출 (기준선) | 0.990 | 0.035 | 0.717 | 0.473 | +0.6%p |
| 가우시안 코퓰라 | 0.991 | 0.022 | 0.668 | 0.604 | −5.3%p |
| 순차 CART | 0.990 | 0.010 | 0.481 | 0.832 | −13.6%p |

→ 원본 행이 있으면 CART가 관계까지 거의 그대로 재현한다. 코퓰라는 범주형이 많으면 관계가 약해진다.

규칙 · 시뮬레이션 (원본 없이, 사용자 1만 명)

|---|---|---|
| 우대 만기 비율 | 58.5% | 보정 목표 55% (진행 중 계좌 제외 후) |
| 이탈 위험 후반/초반 | 0.38 | KKBox 실데이터 0.39 |

## 왜 v1.3은 규칙 · 시뮬레이션인가

- 통계 기반(CART · 코퓰라)과 딥러닝은 **원본 행을 학습**해야 한다. 은행 고객 원본이 없으므로 생성기로 쓸 수 없다.
- 금융권도 원본이 없거나 쓸 수 없을 때는 시뮬레이션을 쓴다: 영국 FCA 합성데이터 전문가그룹 보고서(2024)는 사기 데이터셋에
  에이전트 기반 시뮬레이션을 쓴 이유로 "실데이터 입력이 필요 없다"를 들었고(전문가 판단은 필요), PaySim(2016) · IBM AML 합성 거래(2023)도
  같은 방식이다.
- 통계 기반은 버리지 않고 두 곳에 썼다: ① 원본이 있는 공개 데이터에서 생성 방식 비교의 기준, ② IPF로 공개 집계(연령 · 성별 비중)에 맞추기.

`rule_sim_synth.py`는 읽기용으로 줄인 버전이라 파트너 적금 · 다른 상품이 없고, 숫자가 v1.3과 조금 다르다.
